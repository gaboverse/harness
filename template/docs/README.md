# Project documentation

This directory contains the project's canonical documentation.

- `standards/`: shared standards inherited from Harness and project-specific extensions, with ownership identified.
- `project/`: vision, scope, constraints, glossary, and discovery state as needed.
- `specifications/`: requirements and specifications for features or changes.
- `architecture/`: architecture overview and decisions.
- `operations/`: development, testing, release, and operating procedures.

Add documents when needed; do not populate every possible document with placeholders. Template updates must not silently overwrite project-owned decisions.
