# Agent guidance

## Before acting

- Read `system-prompt.md`, relevant project context, applicable standards, and the current specification.
- Identify the requested outcome and current approval state.
- Distinguish confirmed facts, assumptions, proposals, and decisions.

## During work

- Ask focused questions when material uncertainty blocks safe progress.
- Prefer minimal, reviewable changes.
- Follow canonical documents; do not create duplicate sources of truth.
- Do not implement substantial functionality before critical decisions and acceptance criteria are clear.
- Do not silently expand scope or treat your own proposal as approved.

## Before reporting completion

- Run applicable validation in the agreed environment.
- Report checks actually run and their outcomes.
- Disclose failures, unverified behavior, and remaining risks.
- Update canonical documents when implementation changes agreed behavior.
